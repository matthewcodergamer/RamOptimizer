# Chrome Web Store listing draft

## Name

Browser Performance Manager

## Short description

Keep Chrome responsive by monitoring memory pressure and safely suspending inactive tabs.

## Free

- System memory pressure dashboard
- Smart automatic tab suspension
- Manual Optimize now
- Balanced and Smart modes
- 30-minute, 1-hour and 2-hour suspension intervals
- Up to 3 protected websites
- Duplicate-tab cleanup
- Local optimization statistics
- No page content injection
- No browsing data upload

## Pro

Browser Performance Manager Pro adds:

- 5-minute through 24-hour custom suspension intervals
- Maximum Saver / Turbo Saver behavior
- Unlimited protected websites
- Quiet hours
- Local performance history
- Session snapshots and restore
- Higher tab-discard limits per optimization cycle

Pro is sold by the extension developer through the developer's billing website. Google is not the seller of Pro subscriptions.

## Privacy

The extension reads the minimum tab metadata needed to identify safe inactive tabs and uses Chrome's system memory API to measure overall system memory. It does not read page content or inject scripts. Pro license verification is performed locally using a signed license token.
